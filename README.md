# 🍔 Foodie — Food Delivery Website

Build a fully responsive food delivery website using **HTML, CSS, and JavaScript**. This project focuses on creating a modern, user-friendly interface with structured layouts and interactive features, including a functional **Add to Cart** system.

---

## 🔧 Key Features

* ✅ **Responsive Design**
  Optimized for mobile, tablet, and desktop devices.

* ✅ **Add to Cart Functionality**
  Dynamic shopping cart system for managing selected items.

* ✅ **Interactive UI**
  Smooth transitions, hover effects, and engaging user interactions.

* ✅ **Modern Layout**
  Clean and flexible design using **Flexbox**.

---

## 📚 Technologies Used

* ✅ **HTML5** — Semantic and accessible structure
* ✅ **CSS3** — Modern styling with responsive design techniques
* ✅ **JavaScript** — Dynamic behavior and interactivity

---

## 🚀 Getting Started

1. Clone the repository:

   ```
   git clone https://github.com/muhammad-rizwan-wp/foodie-webapp.git
   ```
2. Open the project folder
3. Run the `index.html` file in your browser
